Destinations & Activation

Where insight becomes action — pushing audiences, personalization, and data out to the platforms and systems where customer experience actually happens.

⚡ Real-time Activation

📧

Email Platforms (SendGrid)

Triggers transactional and campaign email within 5 minutes.
📱

SMS / Push (Twilio, FCM)

Time-sensitive alerts, with strict consent and frequency caps.
📢

Ad Platforms (Google, Meta)

Syncs hashed audiences for targeting and spend-saving suppression.
🖥️

Web / App Personalization

Serves personalized content back into the site or app.
💬

On-site Messages

In-session banners and modals that react within the same visit.

How to Consume

Cxos.Activation.Api · Command

POST /v1/activate
{ "customer_key": "cust_004821", "trigger": "cart_abandonment",
  "channel": "email", "template_id": "cart_recovery_v3" }

202 Accepted { "dispatch_id": "disp_9931", "routed_to": "Cxos.Connectors.SendGrid" }

💾 Batch / File Exports

🦺

S3 / GCS / Azure Blob

Scheduled Parquet/CSV drops into a partner's own cloud storage.
🔒

SFTP / FTPS

Secure legacy file transfer for partners who require it.
❄️

Snowflake / BigQuery

Zero-copy Iceberg attachment or a scheduled warehouse load.
🧞

Databricks / Redshift

Direct Spark attachment for data science, scheduled loads for BI.

How to Consume

Cxos.Connectors.BatchExport · Command

POST /v1/exports/schedule
{ "table": "marts.order_fact", "destination": "s3://partner-northwind/cxos-exports/",
  "format": "parquet", "schedule": "0 2 * * *" }

🔗 APIs & Webhooks

🔀

Journeys & Automation

Signed webhook events for external journey-orchestration tools.
🌐

External Applications

An authenticated REST API for partners to pull data on demand.
🧰

Custom Integrations

A shared connector template for destinations that don't fit the mold.

How to Consume

Cxos.Activation.Api · Command

// Register a webhook subscription — CXOS pushes to you, signed:
POST /v1/webhooks/subscribe
{ "event_types": ["propensity.threshold_crossed"], "endpoint": "https://hooks.acme.example/cxos" }

// Or pull on demand via the External Applications API:
GET /external/v1/profile/cust_004821
Authorization: Bearer <partner-scoped-token>

🔄 Reverse ETL / CDP Sync

🤝

CRM (Salesforce)

Pushes LTV and propensity into the tool sales already lives in.
🎧

Support (Zendesk)

Surfaces customer context in the agent sidebar before the ticket opens.
📣

Marketing (HubSpot)

Syncs governed segments so campaigns match ad-platform audiences.

How to Consume

Cxos.Connectors.Salesforce / .Zendesk / .HubSpot · Command

// Not called directly — field mappings drive the sync automatically:
{
  "salesforce_object": "Account",
  "field_mappings": { "CXOS_LTV_Band__c": "marts.customer_profile.ltv_band" },
  "sync_method": "bulk_api_upsert", "schedule": "hourly"
}
